# Bundled project skills

The bundle is repository-local and portable. Read the relevant `SKILL.md` before a change; no installation into a personal Codex directory is required. [AGENTS.md](../AGENTS.md) supplies project rules, and [docs/SKILLS.md](../docs/SKILLS.md) records provenance, copied-source hashes and scoped skill evaluation.

| Work | Read |
| --- | --- |
| Every task: truthful claims and purposeful output | [Anti-slop core](../antislop.md) |
| Numerical model, units, projection, exposure or historical comparison | [ABO numerical modeling](abo-numerical-modeling/SKILL.md) |
| FastAPI, React, contracts, dependencies, setup or CI | [ABO Python + React](abo-python-react/SKILL.md) |
| Independent checks, scientific evidence or skill evaluation | [ABO QA](abo-qa/SKILL.md) |
| UI layout, color, controls, motion or responsive behavior | [Anti-slop UI](antislop-ui/SKILL.md) and [design direction](../DESIGN.md) |

Anti-slop applies during planning and development. The UI skill contains a labeled ABO extension covering redundant labels and buttons. Keep copied upstream text and its provenance intact. The corrected contrast definition in `AGENTS.md` governs review.

The ABO-specific skills are guidance, not scientific certification. Existing unseen-case QA demonstrates useful findings for those cases; historical accuracy and final graphics/accessibility gates remain separate. Use the current gap register instead of old Stage 0 descriptions when assessing readiness.
