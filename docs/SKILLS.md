## Selection rationale

The curated `openai/skills` catalog was checked through the installed skill-installer. It did not offer a dedicated Python/React ashfall or numerical deposition skill. Creating short project-specific guidance avoids implying that an unrelated general skill covers the physics.

Existing Playwright browser automation is relevant when simulator interactions need browser evidence. Its installed CLI guidance was reviewed, but it is an optional environment capability rather than a project runtime dependency. The foundation can be checked through the available browser tools; no browser test framework was added solely to mirror a starter screen.

Jupyter notebook authoring is optional for later equation exploration and sensitivity analysis. It is not required to run this application, and no notebook is created during preparation. PDF/document/slide skills would become relevant only for later report or presentation requests. Deployment, authentication, database, and equity-research skills do not match this preparation scope.

## What QA can establish

The independent QA agent evaluates realistic supplied review cases and validates skill structure. This can demonstrate that the bundle helps identify concrete unit, modeling, integration, or design mistakes in those cases. It cannot prove causal improvement over an agent without the skills, physical model accuracy, real historical replication, or complete future UI behavior.

See `docs/QA_REPORT.md` for observed checks, actionable findings, and untested areas. Skill YAML validation proves formatting and discoverability metadata only; behavioral evidence must identify what the reviewer actually did.

QA also found that the copied anti-slop R-25 labels 18px text as large, which is too permissive. `AGENTS.md` records the correct [W3C large-text definition](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) for future review while preserving the gathered source. Every current starter text-color pair exceeds 4.5:1, so this caveat does not create a present contrast defect.
